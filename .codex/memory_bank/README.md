# Codex Project Memory Bank

This is persistent project memory for Codex agents. It is **not** app runtime code.

## Rules

- **Query this first** before scanning the repo.
- **Keep entries concise** — one decision or pattern per file.
- **Update only relevant files** after a task; no full refreshes unless asked.
- **Do not load** files here as skills or app source.

## Structure

| Folder | Contents |
|---|---|
| `decisions/` | Architecture decisions and trade-offs |
| `patterns/` | Conventions and repeated implementation patterns |
| `architecture/` | Module, layer, and component structure notes |
| `troubleshooting/` | Known issues and proven fixes |
| `workflows/` | Development and memory-management workflows |

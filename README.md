# Daily Health Coach

Local-first Android MVP for health, fitness, recovery, nutrition, and habit tracking.

## Current Phase

Phase 1 foundation is in progress:

- Kotlin Android app
- Jetpack Compose UI
- Room local database
- Clean architecture package structure
- Seeded default habits
- Seeded macro target with 170-200g protein goal
- Basic Daily Dashboard screen using Room-backed habit and macro data
- Placeholder values for tracking areas that are not implemented yet

## Run Locally

1. Open this folder in Android Studio:

   `C:\Users\darks\OneDrive\Documents\App`

2. Let Android Studio sync Gradle.

3. Select an Android emulator or connected Android device.

4. Run the `app` configuration.

## Notes

- No backend, cloud sync, external APIs, Health Connect, or barcode scanning are included.
- Dashboard placeholder values are intentional until food, steps, sleep, recovery, and recommendation logging are implemented.
- Recommendations are general wellness guidance only and are not medical advice.
